# Data Visualization with Matplotlib & Seaborn

This project demonstrates informative data visualization using a real-world Iris dataset.

## Features
- Histograms for numerical distributions
- Box plots for spread and outliers
- Bar charts for category comparisons
- Scatter plots for relationships between variables
- Correlation matrix and heatmap
- Custom color palettes and plot formatting
- Clean, labeled charts suitable for presentations

## Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The Iris dataset is loaded using Seaborn's built-in dataset loader.

## Run
```bash
pip install -r requirements.txt
jupyter notebook notebooks/Data_Visualization.ipynb
```

The notebook saves generated charts into the `visualizations/` folder.
